# Decision Records

Anything that changes the shape of the product gets recorded here: adding a dependency, changing the
module set, changing a design principle, dropping a screen, reversing a Phase 1 claim.

**Why bother.** Every member has to defend the whole document in the viva. "Why did you choose a
responsive website over a native app?" has one right answer and all four of you need it. A decision
argued in a group chat in Week 6 is gone by Week 15. A decision recorded here is not.

## How

1. Open an issue labelled `type:decision` and let the group weigh in.
2. Copy `_TEMPLATE.md` to `NNNN-short-title.md`, next number in sequence.
3. Record the outcome, including the options rejected and why.
4. Superseding an old decision does not delete it. Mark it superseded and link the new one.
