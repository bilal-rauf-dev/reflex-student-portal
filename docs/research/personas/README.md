# Personas

Two personas, one per user group in the charter. Built **from the Phase 2 data**, not from
imagination. A persona nobody can trace back to real interview evidence is decoration.

Each persona file states, at the bottom, which participants and survey responses it is drawn from.

## Template

```markdown
# [Name], [age] — [one-line role]

**Represents:** Group A / Group B
**Drawn from:** P1, P4, P7 and survey responses n=NN

## Context
Year, courses, device, connectivity, where and when they use the portal.

## Goals
What they are actually trying to achieve. Not "use the portal".

## Frustrations
From the data. Quote where possible.

## Current workarounds
What they already do to compensate. This is the evidence for the product.

## What would help
Stated by them, not designed by us.

## Quote
> "" — P
```
